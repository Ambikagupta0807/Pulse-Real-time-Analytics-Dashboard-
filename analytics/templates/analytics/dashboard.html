Tech Stack
BackendDjango + Django REST Framework — handles data models, API endpoints, and business logic.
DatabasePostgreSQL — stores all event records permanently with relational integrity.
Real-Time LayerDjango Channels + Redis — pushes live updates to connected clients via WebSocket (Pub/Sub pattern).
Data AnalysisPandas — aggregates raw events into summary statistics (counts, breakdowns).
FrontendHTML/CSS/JS + Chart.js — renders live, auto-updating visualizations without page reloads.
ProtocolWebSocket — maintains a persistent connection so the server can push data instantly, instead of the client repeatedly polling.
